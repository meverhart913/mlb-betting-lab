# Python scripts

- `build_pitcher_model.py`: leakage-safe feature engineering, walk-forward model evaluation, market benchmarking, and edge backtest.
- `download_mlb_enrichment.py`: resumable MLB StatsAPI enrichment downloader.
- `stat_import.py`: base historical game schedule/results downloader.
- `convert_odds.py`: converts the historical odds JSON export into split CSV files.

Run scripts from the repository root so relative input/output paths are predictable.
